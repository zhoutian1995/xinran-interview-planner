# 选题评分与采访边界

## 六维评分

每项 1-5 分，总分 30 分：

- `guest_fit`：嘉宾是否有一手经历、专业或独特证据。
- `audience_need`：是否对应目标观众正在面对的真实问题。
- `timeliness`：是否存在近期讨论窗口。
- `depth`：能否追到故事、选择、证据、代价和边界。
- `distribution`：是否具有反差、画面、观点或可分享价值。
- `safety`：事实、隐私、伦理和关系风险是否可控；5 分代表风险低。

推荐阈值：

- 24-30：主选题
- 20-23：有条件主选题，需要补证据或收窄范围
- 15-19：备选
- 6-14：删除

任何 `guest_fit` 或 `audience_need` 低于 3 的话题不得成为主选题。任何 `safety` 低于 3 的话题必须先处理风险。

## 追问链

优先使用：具体场景 → 当时选择 → 结果证据 → 付出代价 → 失败反例 → 今天判断 → 对普通人的意义。

回答太泛时：

- “能不能讲一个具体发生过的场景？”
- “当时你还有什么选择，为什么没有选？”
- “什么事实或结果让你确认这个判断？”
- “这套方法对什么人不适用？”

## 敏感议题

- 教育：不把单个家庭经验包装成普遍规律，不替未成年人诊断。
- 疗愈：追问方法来源、证据、适用边界和不适用人群，不做医学承诺。
- 财富：收入、融资、资产和商业结果必须核验来源。
- 女性与家庭：避免窥私和道德评判，聚焦当事人的选择与经验。
- 消费测评：区分检测事实、个人体验和商业合作，注意利益冲突。
- AI/机器人：追问真实使用场景、失败条件、人的责任和被夸大的部分。
